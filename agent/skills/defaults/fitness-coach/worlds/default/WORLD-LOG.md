- 名称：`风痕原野`
- 氛围：`治愈、明亮、风很大的荒野感`

## [世界规则]

这片原野上散布着许多古代遗构。它们不会无条件回应任何人，而会对呼吸、平衡、节奏、力量输出和身体控制产生反应。

你每一次真实训练，都会让身体更能与这些遗构同步。
